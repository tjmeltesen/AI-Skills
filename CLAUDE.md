# Claude Code Guidelines

At session start and after context reset, read and apply [core/session-start/SKILL.md](core/session-start/SKILL.md), which loads Ponytail by default.

Refer to [AGENTS.md](./AGENTS.md) for overarching repository structure, validation rules, and skill authoring standards.
Refer to [JobApplications/AGENTS.md](./JobApplications/AGENTS.md) when executing or modifying skills in the JobApplications pipeline.
Refer to [swe/AGENTS.md](./swe/AGENTS.md) when executing or selecting Software Engineering Process Models. Always critique and select a process model starting with modern agentic models first before falling back to classical models.
